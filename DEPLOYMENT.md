# Render deployment

This project is a Flask application, so it needs a Python web service rather
than a static-site host. The `render.yaml` Blueprint configures the app to run
with Gunicorn and stores its SQLite database and profile pictures on a
persistent disk.

1. Push this repository to GitHub.
2. In Render, choose **New → Blueprint**, connect the repository, and deploy
   the `render.yaml` configuration. The configured Starter service and 1 GB
   persistent disk are paid resources.
3. After the first deploy, open the service URL. The Flask app serves its
   registration page at `/`; it does not need a root `index.html`.
4. To enable password-reset email/SMS, add the corresponding SMTP and Twilio
   environment variables from `.env.example` in the Render dashboard. Set
   `ADMIN_USER_ID` there if an administrator account is required.

The app's secret key is generated by Render. Do not copy local `.env` values
or commit credentials to the repository.
